# Заполнение пропусков PM₂.₅

Эксперимент обрабатывает измерения четырёх постов за 2019–2022 годы на сетке
20 минут. Параметры выбора методов закреплены в
[resources/protocol.json](resources/protocol.json). Общие конструкторы для
других каналов и наборов данных описаны в [TIME_SERIES](https://github.com/Aboba-gif/adrkit-timeseries/blob/3b39759f0ec7b483fe295bfe313747aae050dd92/docs/TIME_SERIES.md).

Для другого набора данных нужно определить собственные каналы, условия проверки
и правило выбора; общие конструкторы не назначают эти условия автоматически.

## Входы и запуск

[Конфигурация](configs/experiment.json) задаёт `data_root`, `output` и `metrics`.
Во входном каталоге нужны 16 CSV в подкаталогах `krz`, `pes`, `sev` и `slc`.
Источник данных указан в [data/pm25/README.md](../../data/pm25/README.md).
Локальные файлы находятся в `data/pm25/raw`; в репозиторий кода CSV не входят.
Пути разрешаются относительно конфигурации. Метаданные исходного экспорта
не устанавливают часовой пояс и физические единицы; эти сведения требуют
отдельного подтверждения.

Из папки проекта:

```text
python -X utf8 -B -m experiments.pm25_imputation --help
python -X utf8 -B -m experiments.pm25_imputation --config experiments/pm25_imputation/configs/experiment.json
```

Полный запуск обучает модели, оценивает искусственные пропуски, выбирает методы,
затем создаёт экспорт всего периода. Для другого расчёта задайте отдельные
каталоги вывода и метрик. По умолчанию результаты записываются в соседнюю папку
`YM2026-results/pm25_imputation`.

## Обучение и проверка

2019–2020 годы используются для обучения, 2021 — для выбора методов,
2022 — для проверки закреплённого правила. Исторические периоды изучались
ранее; протокол зафиксирован перед данной проверкой экспорта. Это
ретроспективная исследовательская проверка с временным разделением данных.
Значения 2022 года не участвуют в выборе метода.

| Метод | Используемые данные |
|---|---|
| `linear` | Линейная интерполяция между исходными значениями непосредственно до и после пропуска; нужны оба значения |
| `network_hgb` | `HistGradientBoostingRegressor` по исходным значениям остальных постов, маскам наличия и календарным признакам; целевой ряд и метеорологические каналы исключены |
| `common_hgb` | Та же модель по соседним постам, концам пропуска, видимому контексту, длине блока, линейной интерполяции и положению отсчёта внутри блока; нужны оба конца и допустимые размеры окна |
| `climatology` | Среднее исходных обучающих значений для пары «месяц, час»; при отсутствии этой группы — общее среднее целевого поста |

Интерполяция и контекстная модель используют наблюдения правее пропуска.
Это заполнение ряда после измерений, а не прогноз будущих концентраций.
Метрики вычисляются на исходных наблюдениях, искусственно скрытых по протоколу.
После этой проверки модели отдельно переобучаются на всех исходных
наблюдениях для заполнения естественных пропусков. Заполненные значения
не используются как новые обучающие метки.

Окна общей модели целиком лежат внутри непрерывных обучающих диапазонов.
Ограничение числа окон применяется к равномерно выбранным допустимым
началам до перебора длин пропусков. Для каждой допустимой длины используются
варианты с доступными соседними постами и без соседей. Каждое включённое
целевое значение имеет одинаковый вес при каждом своём появлении и может
войти в несколько окон или длин. Только исходные наблюдения становятся
целевыми значениями; скрытый блок исключён из признаков целевого ряда.

Внутренние искусственные пропуски имеют длины 1, 3, 12, 36, 72, 216 и
720 отсчётов по 20 минут; граничные — 216 и 720. Режим `actual` сохраняет
исходные соседние наблюдения, `none` скрывает их. В граничных опытах скрыт
также контекст целевого поста до начального или после конечного пропуска.
Окна разных длин могут пересекаться.

Метод выбирается по объединённой средней квадратичной ошибке на `selection`
для каждого поста, длины и режима; требуется не менее восьми блоков кандидата.
При равенстве берётся первый метод в порядке протокола. Естественному
внутреннему пропуску соответствует наименьшая проверенная длина не меньше
его длины, до 720 отсчётов. Для граничных и более длинных пропусков
используется отдельное резервное правило: выбор по граничным блокам длины
720, при их недостатке — по внутренним блокам той же длины, иначе `climatology`.

## Сглаживание

Для заполненного ряда $y\in\mathbb R^n$, положительных весов
$w_i$ и $\lambda\geq0$ сглаживание минимизирует по
$z\in\mathbb R^n$ функционал

$$
  F(z)=\frac12(z-y)^\top W(z-y)
       +\frac{\lambda}{2}\|Dz\|_2^2,
  \qquad W=\operatorname{diag}(w),
$$

где $(Dz)_i=z_{i+1}-z_i$, $i=1,\ldots,n-1$.
Здесь $n$ — число отсчётов, $i$ — их номер; $y_i$ — значение заполненного
ряда, $z_i$ — искомое сглаженное значение. Вектор $w=(w_i)\in(0,\infty)^n$
задаёт веса, $W\in\mathbb R^{n\times n}$ — диагональная матрица весов,
$D\in\mathbb R^{(n-1)\times n}$ — матрица первых разностей,
$\lambda$ — параметр сглаживания.

Граничные значения свободны. При $\lambda=0$ возвращается копия
исходного ряда. Если веса безразмерны, $\lambda$ также безразмерна;
веса задаются протоколом и автоматически не интерпретируются
как обратные дисперсии ошибок.

Нормальные уравнения имеют вид

$$
  Az=b,\qquad A=W+\lambda D^\top D,\qquad b=Wy.
$$

Матрица нормальных уравнений $A\in\mathbb R^{n\times n}$ симметрична
и положительно определена при положительных весах; $b\in\mathbb R^n$ —
правая часть.
Диагностическая относительная невязка равна

$$
  \eta=\frac{\|Az-b\|_\infty}
                 {\|A\|_\infty\|z\|_\infty+\|b\|_\infty}.
$$

Для матрицы используется индуцированная бесконечная норма; при нулевом
знаменателе $\eta$ задана нулём. Она характеризует численную
стационарность, а не точность относительно неизвестных концентраций в пропусках.

В предоставленном протоколе λ=1. Для проверки влияния сглаживания заданы
λ=0, 1, 9 и 81. Веса равны 1 для исходных наблюдений, 0,25 для заполнений
со статусом `artificial_mask_evaluated` и 0,05 для экстраполяций.

## Результат и интерпретация

Файл `pm25_final_2019_2022.csv` содержит колонку `timestamp` и по восемь
колонок с префиксами `Severny_`, `Peschanka_`, `Soloncy_`, `KrAZ_` — всего
33 колонки. Например, `KrAZ_pm25_observed`. Суффиксы: `pm25_observed`,
`pm25_filled`, `pm25_smoothed`, `is_imputed`, `status`, `method`,
`gap_steps`, `adr_observation_weight`.

- `observed` сохраняет исходные значения и NaN.
- `filled` сохраняет наблюдения и заменяет пропуски.
- `smoothed` — отдельное сглаживание, меняющее также наблюдавшиеся значения.
- `adr_observation_weight` — маска наличия исходного измерения.

`is_imputed` отмечает отсутствие исходного измерения; `gap_steps` содержит
длину всего пропуска в отсчётах и равен нулю для наблюдений; `method` задаёт
способ заполнения. Статусы различают исходное значение (`observed`),
проверенные условия заполнения (`artificial_mask_evaluated`), начальную,
конечную, длинную и недостаточно проверенную экстраполяцию
(`leading_extrapolation`, `trailing_extrapolation`, `long_gap_extrapolation`,
`method_support_extrapolation`).

`gap_ledger.csv` описывает пропуски. Его `selection_reference_rmse` —
RMSE на объединённых искусственных пропусках выборки для выбора метода, не стандартное
отклонение отдельного заполненного значения. Каталог метрик содержит ошибки,
годовые сводки и проверку согласованности экспорта. Точность значений
в естественных пропусках не измеряется непосредственно: оценки на искусственных
масках характеризуют только предусмотренные условия проверки.

Заполненные и сглаженные значения не являются независимыми измерениями.
Сопоставление с эпизодами КрАЗ использует исходные наблюдения. Лицензия кода
не определяет права использования сторонних измерений.
