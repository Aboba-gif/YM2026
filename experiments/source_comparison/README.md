# Сравнение регуляризаций источника

Эксперимент сравнивает L² и полную временную H¹-регуляризацию для заданных
профилей источника. Наблюдения синтетические; коэффициенты уравнения и
предыстория источника заданы. Исходная постановка описана в
[configs/protocol.json](configs/protocol.json), параметры расчёта —
в [configs/experiment.json](configs/experiment.json).

## Запуск

Команды выполняются из папки проекта в установленном окружении:

```text
python -X utf8 -B -m experiments.source_comparison --help
python -X utf8 -B -m experiments.source_comparison run --config experiments/source_comparison/configs/experiment.json --source SF03-EC04
```

Без `--source` выполняются все четыре профиля конфигурации: SF01-PG10,
SF01-SB150, SF03-EC04 и SF03-EC06. Для каждого заданы три реализации шума,
три матрицы весов и 17 значений α для каждого штрафа. Это численная серия
с многократным решением прямой и сопряжённой задач.

Пути `protocol` и `output` разрешаются относительно конфигурации.
По умолчанию результаты записываются в `YM2026-results/source_comparison`
рядом с папкой проекта. Для другого расчёта задайте новый каталог.
Продолжение требует совпадения кода, конфигурации и протокола.

В `run.json` записываются конфигурация, контрольные суммы и состояние серии;
отдельные JSON профилей содержат оценки, выбранное α и численную диагностику.

## Ковариация и масштаб регуляризации

Ковариация оценивается по отдельным панелям ошибок с заданным нулевым
средним. W01 использует общий второй момент, W02 — отдельный для каждого
поста. W03 при фиксированных оценках дисперсии выбирает длину
экспоненциальной корреляции по гауссову критерию на заданной сетке.
Межпостовая корреляция не оценивается. Панели разных назначений используют
разные потоки; сопоставляемые условия получают общие стандартные нормальные
числа.

## Модель источника и регуляризация

На интервале $[0,T]$, $T=3$ ч, неизвестный источник представлен непрерывным
кусочно-линейным профилем

$$
  q_a(t)=Q_{\mathrm{ref}}\sum_{j=1}^{p}a_j\varphi_j(t),\qquad
  a\in\mathbb R_+^p,\qquad p=73.
$$

Здесь $a_j$ — безразмерные неотрицательные узловые коэффициенты,
$\varphi_j$ — узловые функции пространства непрерывных кусочно-линейных
функций на временном разбиении, $j=1,\ldots,p$.
Масштаб $Q_{\mathrm{ref}}=100$ задан в C·км²/ч, где C=мкг/м³ — единица
концентрации сценарной модели. Концевые коэффициенты свободны; общий
интеграл восстановленного профиля не фиксируется.

Пусть $F_h(a)\in\mathbb R^N$ — прогноз концентраций дискретной полулинейной
модели с оператором наблюдений, $N=288$: четыре поста и 72 момента времени.
Индекс $h$ обозначает дискретную модель. Пространственное наблюдение использует
гауссово усреднение с площадями ячеек; временное — мгновенный отсчёт.
Известная предыстория на $[-0{,}5,0]$ входит в прямое решение.

Для рабочей положительно определённой ковариации
$\widehat\Sigma\in\mathbb R^{N\times N}$ и $\alpha>0$ строится численный
кандидат задачи

$$
  \min_{a\in\mathbb R_+^p}
  \left\{\frac12r(a)^\top\widehat\Sigma^{-1}r(a)
        +\frac\alpha2 a^\top G_m a\right\},\qquad
  r(a)=F_h(a)-y_{\mathrm{fit}},\qquad m\in\{0,1\}.
$$

Вектор $y_{\mathrm{fit}}\in\mathbb R^N$ содержит наблюдения для оценки
источника; $r(a)$ — невязка; $m$ — номер штрафа.
Положительно определённые матрицы $G_m\in\mathbb R^{p\times p}$ равны

$$
  G_0=Q_{\mathrm{ref}}^2M,\qquad
  G_1=Q_{\mathrm{ref}}^2(M+\tau^2K),\qquad
  M_{ij}=\int_0^T\varphi_i\varphi_j\,dt,\qquad
  K_{ij}=\int_0^T\varphi_i'\varphi_j'\,dt.
$$

Здесь $i,j=1,\ldots,p$, штрих обозначает производную по времени,
$\tau=0{,}25$ ч — её масштаб. При $m=0$ используется L²; при $m=1$ —
полная H¹-регуляризация, включающая профиль и его производную.

Якобиан $J_0=D_aF_h(0)\in\mathbb R^{N\times p}$ линеаризации прогноза
в нулевом неизвестном профиле задаёт опорный масштаб

$$
  \alpha_{\mathrm{ref},m}=\frac1p\operatorname{tr}
  \left(G_m^{-1}J_0^\top\widehat\Sigma^{-1}J_0\right).
$$

$D_a$ обозначает производную по коэффициентам, $\operatorname{tr}$ — след
матрицы. Масштаб вычисляется отдельно для ковариационной модели и штрафа.
Используются 17 значений $\alpha=\alpha_{\mathrm{ref},m}10^\xi$,
$\xi=-6,-5{,}5,\ldots,2$. Линеаризация задаёт масштаб и начальное
приближение; последующее восстановление использует нелинейный прогноз.

Регуляризация выбирается по обычной невзвешенной средней квадратичной ошибке
на отдельной выборке $y_{\mathrm{select}}\in\mathbb R^N$:

$$
  E_{\mathrm{select}}(\alpha)=\frac1N
  \left\|F_h(\widehat a_\alpha)-y_{\mathrm{select}}\right\|_2^2.
$$

Здесь $\widehat a_\alpha$ — принятый численный кандидат,
$\|\cdot\|_2$ — евклидова норма. Выбирается минимальная ошибка;
при точном равенстве — большее α. Истинный источник и последующая
проверочная выборка в выборе не участвуют. Принятие численных условий
не доказывает глобальный минимум. В [E05](../source_recovery/README.md)
используется другая сетка из 25 значений и допуск близости ошибок.

L-кривая использует кривизну со знаком в координатах логарифмов
ковариационно взвешенной нормы невязки и нормы штрафа при возрастании α.
Диагностический индекс соответствует допустимому положительному максимуму;
два отсчёта с каждого края исключаются. При непринятом кандидате,
недопустимых нормах или отсутствии разрешимого положительного максимума
индекс не определён. L-кривая не задаёт выбранное для восстановления α.
Общий критерий описан в
[Regularization Tools](https://www.imm.dtu.dk/~pcha/Regutools/RTv4manual.pdf).

Объявленная единица C не подтверждает единицы и калибровку исторических CSV.
Интенсивность двумерного сценарного источника не является суммарным
массовым расходом предприятия.

## Рисунки из сохранённых решений

```text
python -X utf8 -B -m experiments.source_comparison figures --config experiments/source_comparison/configs/plots.json
```

В [plots.json](configs/plots.json) отдельно заданы научная конфигурация,
каталог сохранённых решений и новый каталог рисунков. Формируются рисунки,
таблицы CSV и `manifest.json`; повторное восстановление источника не выполняется.
Все указанные профили должны иметь завершённые записи с согласованными
контрольными суммами.

## Область результата

Сравнение относится к указанным моделям, сеткам и реализациям ошибок.
Оно не устанавливает универсального преимущества регуляризации и не
восстанавливает физические выбросы по измерениям. Проверки сетки и области
составляют численную диагностику; общая теорема сходимости из них не следует.
Общие интерфейсы: [расширение ADR](https://github.com/Aboba-gif/adrkit-timeseries/blob/3b39759f0ec7b483fe295bfe313747aae050dd92/docs/EXTENDING.md).

## Передача настроек и совместимость сохранённых результатов

Масштаб интенсивности `execution_config.basis.Qref` используется в нагрузке,
ошибках источника, таблице восстановленных профилей и рисунках. Временной
масштаб `execution_config.basis.tau_hours` должен совпадать с
`selector.tau_hours`. Числа калибровочных выборок в
`execution_config.calibration.panels.calib_noise` и
`calibration_and_splits.panels.calib_noise` также должны совпадать.
Несогласованное объявление отклоняется при загрузке протокола.
Принятая серия сохраняет Qref = 100, tau_hours = 0,25 и 32 выборки.

Для отдельных рисунков берётся первая реализация в объявленном порядке.
Для рисунка концентраций используется W03, если этот вес объявлен; иначе
используется первый объявленный вес. Реализация и вес указаны в сохранённых
записях и таблицах CSV.
Сводные таблицы и рисунок ошибок используют все объявленные реализации и
веса; число выбранных оценок приводится в таблицах отдельно от описательных медиан.

Сохранённые результаты должны содержать явный `q_reference`, совпадающий
с масштабом протокола. Отсутствующий или несогласованный масштаб отклоняется.
