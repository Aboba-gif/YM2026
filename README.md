# YM2026

Научные эксперименты по восстановлению источника q(t), влиянию наблюдений и
ковариационных весов, заполнению пропусков PM₂.₅ и сопоставлению модельных
откликов с эпизодами КрАЗ. Общие численные компоненты поставляются отдельной
[библиотекой adrkit-timeseries](https://github.com/Aboba-gif/adrkit-timeseries/blob/3b39759f0ec7b483fe295bfe313747aae050dd92/README.md).

## Установка

Нужен Python ≥3.12; для установки библиотеки из GitHub требуется Git.
Из папки `YM2026` в PowerShell:

```powershell
python -m venv .venv
& .venv/Scripts/python.exe -m pip install -c constraints-tested.txt -r requirements.txt "adrkit-timeseries @ git+https://github.com/Aboba-gif/adrkit-timeseries.git@3b39759f0ec7b483fe295bfe313747aae050dd92" "pytest>=8"
. .venv/Scripts/Activate.ps1
```

В Linux и WSL используйте `python3` и `.venv/bin/python`, затем активируйте
окружение командой `source .venv/bin/activate`.
`requirements.txt` перечисляет прямые вычислительные зависимости приложения.
Команда закрепляет ревизию библиотеки. При локальной разработке замените
аргумент `adrkit-timeseries @ git+...` путём к её папке, например
`"../adrkit-timeseries"`.
`constraints-tested.txt` задаёт версии зависимостей для Python 3.12.14 в Windows.
Команды ниже используют `python` из выбранного окружения.

## Организация проекта

| Каталог | Содержимое |
|---|---|
| `experiments/` | Пять постановок, их команды, настройки и протоколы |
| `data/pm25/raw/` | Локальные исходные CSV четырёх постов; в репозиторий кода не входят |
| `tests/` | Тесты научных постановок и чтения их результатов |

Входы и каталоги результатов задаются в конфигурации каждого эксперимента.

Модули `source_recovery/analysis` и `observation_sensitivity/analysis`
содержат сводки и рисунки по сохранённым результатам. Их команды описаны
в руководствах соответствующих экспериментов.

Рисунки содержат данные, деления, подписи осей и краткие легенды серий
и маркеров. Заголовки и пояснения
добавляются при вёрстке презентации или статьи. Табличные результаты
сохраняются в CSV; изображения таблиц не создаются.

## Эксперименты

| Постановка | Руководство |
|---|---|
| Сравнение L² и полной H¹-регуляризации при заданном источнике | [source_comparison](experiments/source_comparison/README.md) |
| Восстановление шести профилей q(t) при разных условиях измерения | [source_recovery](experiments/source_recovery/README.md) |
| Влияние операторов наблюдения и ковариационных весов | [observation_sensitivity](experiments/observation_sensitivity/README.md) |
| Заполнение пропусков PM₂.₅ на четырёх постах | [pm25_imputation](experiments/pm25_imputation/README.md) |
| Сопоставление заданных модельных откликов с эпизодами КрАЗ | [kraz_alignment](experiments/kraz_alignment/README.md) |

Каждая постановка содержит файл `configs/experiment.json`. Пути в нём
разрешаются относительно этого файла. Для отдельного запуска задайте собственный
каталог вывода. Параметры научных серий перечислены в их протоколах.

Например, из папки проекта:

```text
python -X utf8 -B -m experiments.source_comparison --help
python -X utf8 -B -m experiments.source_comparison run --config experiments/source_comparison/configs/experiment.json
```

Источник измерений указан в [описании исходных данных](data/pm25/README.md).
Локальные CSV четырёх постов находятся в `data/pm25/raw`; в репозиторий кода
они не включены. Конфигурации по умолчанию
записывают результаты в соседнюю папку `YM2026-results`. Для переноса приложения
сохраните исходные данные, настройки и доступную установленную библиотеку.

`observation_sensitivity` использует завершённый результат `source_recovery`:
сначала выполните E05, затем E06. Их конфигурации задают связанный каталог
результатов. Для повторения этой серии перед запуском Python задайте
`OPENBLAS_NUM_THREADS`, `OMP_NUM_THREADS` и `MKL_NUM_THREADS` равными `1`.
Число процессов для независимых групп задаётся при запуске.
В Windows параметр `-X utf8` позволяет выводить русские подписи независимо
от кодировки терминала.

Синтетические исследования восстанавливают q(t) при заданных коэффициентах
уравнения. В них C — заданная единица концентрации модели, мкг/м³; это
объявление не подтверждает физические единицы исторических CSV. Восстановление этих коэффициентов не реализовано. Сопоставление
с эпизодами КрАЗ не определяет историю физических выбросов предприятия.
Заполненные и сглаженные значения не являются независимыми измерениями.

## Тесты

```text
python -X utf8 -B -m pytest -q
```

Тесты используют настройки научных постановок и малые искусственные данные.
Код распространяется по [MIT-лицензии](LICENSE). Условия использования
измерений определяются отдельно от лицензии кода.
