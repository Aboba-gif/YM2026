# Исходные измерения PM₂.₅

Источник данных — [система мониторинга воздуха Красноярска](https://air.krasn.ru/).

Исходный набор состоит из 16 CSV за 2019–2022 годы: по четыре годовых файла для постов Северный (`sev`), Песчанка (`pes`), Солонцы (`slc`) и КрАЗ (`krz`). Файлы не заполнялись и не сглаживались. Локальные данные находятся в `raw`; в репозиторий кода CSV не включены.

Они используются в `pm25_imputation` и `kraz_alignment`. Для другого набора данных задайте его каталог в конфигурации. Метаданные исходного экспорта сами по себе не подтверждают часовой пояс и единицы измерения. Условия использования данных определяются отдельно от MIT-лицензии кода.
